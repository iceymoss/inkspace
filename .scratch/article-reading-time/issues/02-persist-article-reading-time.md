# 02: 新建和编辑博客文章时保存预计阅读时长

**What to build:** 作者和管理员新建或编辑博客文章后，该文章持久保存基于最新正文的预计阅读时长；知识库内容发布成博客文章时同样遵循文章规则，但知识库文档自身的统计保持原样。

**Blocked by:** 01: 历史博客文章详情展示预计阅读时长（统一估算规则与详情展示已可用）。

**Status:** ready-for-agent

**Progress:** 实现与验收检查已完成：创建、编辑和知识库发布/重新发布在隔离 MySQL/Redis 下验证，编辑前预填旧缓存并确认失效后读取最新正文和时长；完整 Go 测试、vet 和构建通过。待代码评审和提交。

- [x] 新建与编辑博客文章时依据当次正文计算并写入既有时长字段，空或极短正文结果不小于 1 分钟；不依赖调用方传入时长。
- [x] 普通用户和管理员入口一致；发布或重新发布知识库内容为博客文章也按相同规则更新文章时长，不修改知识库文档统计。
- [x] 后续详情请求使用已保存时长；编辑此前时长为零的历史文章后存储新估算值。
- [x] 测试保存行为与当前文章正文同步，覆盖创建和编辑；检查已有测试、完整 Go 测试和构建，具备隔离服务时验证数据库/缓存，否则记录未验证范围。
- [x] 复核当前工作区已有的未提交预实现及测试，不将其视为已完成或自动通过验收。
