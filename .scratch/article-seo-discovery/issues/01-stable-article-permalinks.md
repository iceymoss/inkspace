# 01: 稳定文章永久链接

**What to build:** 为博客文章建立持久化、全局唯一且默认不可变的 slug URL，并让新旧文章访问、公开查询 API 和博客前端路由使用稳定的 slug，同时保留内部数字文章 ID 能力。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 文章记录拥有全局唯一、持久化的规范 slug；slug 只使用安全的单路径段格式，软删除、草稿和私密文章也继续占用 slug。
- [ ] 新文章创建时自动生成 slug；中文、英文、数字、特殊字符、空结果、超长标题和重复标题都有确定性处理，冲突不会覆盖已有记录。
- [ ] 历史文章可以通过可审查、幂等的迁移/回填流程获得 slug；已有非空 slug 不被重写，重复执行不会产生新的重复后缀。
- [ ] 数据库在历史数据完成校验后建立全局唯一约束；迁移发现无法处理的冲突时显式失败，不删除或静默跳过数据。
- [ ] 公开 slug 查询接口只返回 published 且未软删除的文章，不能通过状态、作者或 show-all 类参数绕过过滤；文章响应携带 slug 并保留数字 ID。
- [ ] `/blog/<slug>` 能访问公开文章；已发布的 `/blog/<id>` 由服务端返回 301 到当前 slug；草稿、私密、软删除和不存在文章统一返回 404。
- [ ] 浏览器文章路由使用 slug，收藏、评论、编辑等内部操作仍能使用返回的数字 ID。
- [ ] 覆盖 slug 生成、冲突、软删除占用、迁移幂等、公开过滤、slug API、301/404 和前端 slug 路由的自动化测试。
