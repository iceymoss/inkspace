# 02: 文章发布时间与公开文章集合

**What to build:** 建立所有公开发现功能共同使用的文章发布时间和公开可见性契约，使 feed、sitemap、公开文章页面和 API 对文章状态、首次发布时间和内容更新时间作出一致判断。

**Blocked by:** 01: 稳定文章永久链接

**Status:** ready-for-agent

- [ ] 文章首次从非 published 状态转为 published 时写入 `publish_at`；后续取消发布和重新发布不清空或重置首次发布时间。
- [ ] 历史文章缺失或非法的 `publish_at` 可回填为 `created_at`；有效历史值保留，回填过程可重复并提供可核对的结果。
- [ ] 公开文章集合只包含 published 且未软删除的文章；草稿、私密、软删除和作者可见但公众不可见的文章被排除。
- [ ] 公开文章查询不会被 status、author_id、show_all 等管理查询参数绕过，并使用稳定的次级排序避免同一时间的结果随机变化。
- [ ] 文章内容或公开状态变化可以反映到 `updated_at`；浏览量、收藏数和评论数等互动计数变化不会伪造内容更新时间。
- [ ] 文章 feed 时间、sitemap lastmod 和公开集合排序分别遵循首次发布时间与内容更新时间的既定语义。
- [ ] 在隔离 MySQL 中覆盖首次发布、取消/重新发布、历史回填、异常值、公开过滤、软删除和稳定排序测试。
