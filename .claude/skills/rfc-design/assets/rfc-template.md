## Detailed design

按数据流或组件展开。以下子节按需保留。

### Shared data and storage contract

定义键、字段、类型/范围、可选项、规范化、长度/端序/校验、非法输入和 schema 演进。分别定义 absent、null、empty、delete 与 corrupt。给可核算示例和共享 codec/API 的职责。

### API contract

| 方法/路径 | 身份与资源资格 | 请求及校验 | 成功响应及确认范围 | 错误/部分成功 |
|---|---|---|---|---|

说明替换或合并、重复请求、并发冲突与框架原生错误。

### Publication/workflow/ingest

写清触发、执行身份与复用、payload/version 绑定、活动输入、持久化确认点、排序/去重、永久/暂时失败、重试预算和终态。

### Runtime reads and activation

说明可信选择身份、查找优先级、依赖缺失、缓存、刷新触发、候选校验、原子激活和过期结果防护。明确在途请求与后续请求的行为。
