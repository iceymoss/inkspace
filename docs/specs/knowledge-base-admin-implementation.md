# 知识库后台实现说明

## 管理入口

管理后台侧栏「知识库」包含概览、工作区、文档、分享链接、资源占用、配额设置、审计日志。API 位于 `/api/admin/knowledge`，复用管理员鉴权。

## 已接入

- 工作区/文档筛选、分页、元数据详情、下架/恢复、软删除；删除工作区级联处理文档、目录、分享链接、版本和成员。
- 分享链接按生效/禁用/过期筛选及强制删除。
- 处置必填理由，审计记录和业务变更同事务；通知在提交后发送，重复审核不重复通知。
- 管理员正文读取独立限制为公开且已发布、工作区及文档未下架的内容。
- Wiki 统计、列表、树、详情以及通用文档详情/文件访问和分享链接接入下架判定。
- 配额复用 settings：默认 10 个工作区、500 篇文档、1024 MB；0 不限制，新增工作区/文档/上传附件执行校验。
- 资源占用按当前文档 AttachmentID 聚合；概览提供连续七日趋势和公开文档浏览量排名。
- 作者详情下架提示，通知支持文档跳转与工作区列表跳转。

## 迁移

新增审核列、通知 DocID 和 admin_audit_logs 由既有 AutoMigrate 执行。配置键缺失时使用默认值，无需预先插入 settings。

## 验证

已执行 Go 全量测试、go vet、go build，以及 admin/blog 两个前端生产构建。新增纯单元测试覆盖私有 DTO 正文字段省略、趋势补零、非法配额键拒绝、审核请求校验、分享审核判定和全部管理 API 无登录鉴权。

尚未进行真实 MySQL/Redis 与浏览器端到端联调；事务回滚、并发审核及聚合 SQL 的真实数据库行为仍需集成验证。现有纯单测通过不等同于这些场景已完成验证。
